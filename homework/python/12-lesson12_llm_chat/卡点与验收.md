## 原理（小白话）
- **非流式 vs 流式**：前者一次 JSON 里已有整句；后者像字幕一行行来，客户端自己拼。
- **`data:` 与 `[DONE]`**：`text[5:]` 去掉前缀；见 `[DONE]` 必须 `break`（不是 `continue`），否则后面的行还会被拼进去。
- **`delta` 可能没有 content**：流式中间行有时只带角色/空增量，先用 `"content" in delta` 再取。
- **MockTransport**：按路径区分 `/stream` 多行文本 vs 普通 JSON；不进真实网络。
- **密钥不进输出**：检查函数只返回状态词；头里的 Bearer 也不要 print。

## 卡点
1. 流式行 `delta` 无 `content` → `KeyError`；先 `in` 判断。
2. 见到 `[DONE]` 用 `continue` 而不是 `break` → 结束标记后的文字被拼上。
3. 打印了环境文件或 `Authorization` → 输出泄漏密钥；返回值只留回复或「已配置」。
4. `data:` 后不是本课认的 JSON → `JSONDecodeError`；先对形状再改解析。
5. 误以为有环境变量就会改 demo 输出 → 主流程固定走本地剧本；可选调用在 `chat_with_config`，由练习显式传入文本。
6. 用系统 python → 可能缺 httpx；一律 `.venv/bin/python`。
