## 复述
- 函数用 `def 名字(参数):` 定义；定义本身不跑函数体，只有调用时才执行。
- `return` 把结果交回调用处并结束这次调用；只 `print` 不 `return`，外面拿到的是 `None`。
- 参数是这次调用传入的数据；函数内赋值的名字是局部的，和外面同名不共用。
- 空列表没有平均值 → 先判 `len == 0` 再除，返回 `None`（不是 0）。
- 差额：已达标或超额返回 0，不要负数分钟。

## 原理（小白话）
- **函数 = 给一段指令起名字**：`def` 只是把菜谱写进菜单；`total_minutes([...])` 才是点菜，解释器跳进函数体跑完，再带着 `return` 的值跳回原处继续。
- **参数进局部**：调用时实参装进参数名这个「临时抽屉」；函数里再赋值的 `total` 也是抽屉里的，出函数就没了。外面的 `total = total_minutes(...)` 是另一只抽屉，靠返回值接结果。
- **为什么要函数**：同一套求和/平均规则给不同列表用，只改调用处的数据，不用复制粘贴循环；改规则只改一处。
- **`None` vs 0**：`[]` 的平均是「没有值」→ `None`；`[0]` 的平均是真的 `0.0`。显示时用 `average is None` 分支，别对 `None` 做 `.2f`。

## 卡点
1. `return` 缩进错放进 `for` 里 → 只加第一条就返回（讲义表第一条）。
2. 函数里只 `print`、外面又 `print(调用)` → 多打一个 `None`。
3. 空列表忘先判长度 → `ZeroDivisionError`；或误把「无平均值」当成 `0`。
4. `count_passed` 若写成 `>` 而不是 `>=`，恰好 60 会漏算。
5. `longest_session([])` 必须先判空再读 `records[0]`，否则 `IndexError`；`[0]` 应返回 `0` 不是 `None`。
