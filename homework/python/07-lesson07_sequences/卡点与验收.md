## 复述
- 列表 `[]` 按顺序装多个值；索引从 0 起，`[-1]` 是最后一项；`len` 数个数。
- 切片 `a[start:stop]` 含头不含尾；越界通常截到实际范围，单个索引越界会报错。
- 列表可变：`append` 末尾加、`a[i]=x` 改、`remove` 按值删、`del a[i]` 按索引删；`append` 返回 None，不要赋回。
- 字符串也能索引/切片/`len`/`for`，但不可原地改字符；`strip`/`replace` 产生新串，要保留就赋值。
- 空列表先 `len == 0` 再读，否则 `IndexError`。

## 原理（小白话）
- **列表在内存里**：名字指向「一排格子」的容器；格子里依次放值。`records[0]` 是去第 0 格读；`append` 在末尾再加一格；改 `records[0]=30` 是改同一排格子里的内容，所以列表叫可变。
- **`other = records` 不复制**：两个名字指同一排格子；改一边另一边也变。要独立副本用 `other = records[:]`（本课整数列表够用）。
- **字符串不可变**：名字指向一整段文字；`strip`/`replace` 不是改原段，而是造一段新的给你；不赋值，原变量仍指旧段。所以 `print(replace(...))` 能看到新串，但 `clean_title` 还是旧的。
- **索引 vs 切片**：索引要精确命中一格，空了或越界就炸；切片是「从这儿到那儿剪一段」，剪空了就给 `[]`，一般不炸。

## 卡点
1. `records = records.append(20)` 会把变量变成 `None`——差点踩；讲义表提醒了，记牢：直接 `append`，别赋回。
2. `remove(40)` 删的是**值**不是「第40个」；和 `del records[1]`（按位置）容易混。
3. 字符串 `replace` 后若不赋值，原文不变——demo 里「替换后」和「原文」对照才真正懂。
4. 切片含头不含尾：`[:2]` 是前两项（索引0、1），不是到索引2。
