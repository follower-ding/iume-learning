## 原理（小白话）
- **切分**：把长笔记拆成可比较的小段；句号切句或固定长度切块都行。
- **本地向量桩**：每个字落到某个格子并计数；同一输入 → 同一列表，方便测，但不是语义嵌入。
- **余弦相似度**：看两个方向有多像；全 0 向量没方向，返回 `0.0`。打印的 `0.69`/`0.50` 只对应当前句子和 16 格。
- **选片段再拼提示**：先找最接近问题的笔记，再写成「根据笔记回答…」，给后面的对话函数用；本课示例不联网。
- **平分与空列表**：`>` 才替换，相等留先到；空笔记不硬选，返回 `None`。

## 卡点
1. `size` 为 0 → 起始位置不前进，死循环；`< 1` 直接返回 `[]`。
2. 空笔记仍硬选一段 → 先判断空列表，返回 `None`。
3. 平分时用 `>=` → 会换成后一段；应用 `>` 保留先出现的。
4. 把 `0.69` 当成「语义相关」→ 只是字符计数在 16 格下的结果；换格子数要重跑。
5. 没有密钥仍调嵌入接口 → `request_embeddings` 先判空密钥。
6. 用系统 python → 可能缺依赖；一律 `.venv/bin/python`。
