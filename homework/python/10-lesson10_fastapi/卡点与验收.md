## 复述
- FastAPI 用 `@app.get` / `@app.post` 把函数登记到路径上；装饰器写法等于「定义完再 `fn = decorator(fn)`」。
- 一次请求先看成：方法、路径、状态码、正文。`GET` 读、`POST` 交；`200` 表示已处理；本课正文是 JSON，程序里用字典。
- `class EchoIn(BaseModel)` 是字段清单；`message: str` 让 FastAPI 检查 POST 正文。缺字段 → `422`；空字符串仍是 str，默认会原样送回，要拒绝需自己 `HTTPException(400, ...)`。
- `TestClient(app)` 在**进程内**发请求，不必长期开 uvicorn；课检跑 `demo.py` 即可。`if __name__ == "__main__":` 包住打印，uvicorn 导入 `demo:app` 时不会刷练习输出。
- 岗位短轨：一律用 `.venv` 里的解释器；`TestClient` 依赖已装的 `httpx2`。

## 原理（小白话）
- **接口**：别人用方法+路径敲门，你的函数回字典；FastAPI 帮你把字典变成 JSON、把请求正文按 `BaseModel` 拆开。
- **装饰器登记**：`@app.get("/health")` 不是马上跑函数，而是告诉应用「有人 GET /health 时再调它」。
- **TestClient**：同一进程里模拟浏览器/curl，状态码和 `response.json()` 立刻能拿，适合课检与单元测；真要对外服务再 `uvicorn demo:app`。
- **422 vs 400**：缺字段/类型不对是框架校验（422）；业务规则（空消息不许）自己 `raise HTTPException(400, detail=...)`。
- **`__name__ == "__main__"`**：直接 `python demo.py` 才打印；被 uvicorn 导入时只暴露 `app`。

## 卡点
1. 用系统 `python3` → `ModuleNotFoundError: fastapi` / `httpx2`；改用 `.venv/bin/python`。
2. POST 忘了 `json={"message": ...}` 或键名写错 → `422`。
3. `/health` 误用 POST 或 `/echo` 误用 GET → `405`。
4. 空字符串以为会自动 422 → 不会，它仍是合法 `str`；要拒绝就显式 `HTTPException`。
5. 打印写在模块顶层 → uvicorn 导入时也会打印；放进 `if __name__ == "__main__":`。
6. `len("你好")` 是字符数 `2`，不是字节数；本课按 Python 字符串字符数。
