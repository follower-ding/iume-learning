# AI Lab 第09课：混合检索（hybrid-retrieval）

## 学了啥
同一批文档上同时打两路分：关键词是 BM25，向量仍是第 03 课的字面 TF-IDF 余弦，不是神经网络嵌入。两路原始分不能直接相加——BM25 可以到 3 分，余弦只有 0.23，加总会被关键词路淹没；也不按「这一问的最高分」去除，全库都很弱时第一名会被抬成 1。先压缩再等权融合：`squash = raw / (raw + 2.5)`，`融合 = 0.5 × 向量 + 0.5 × 压缩后的关键词分`。0 还是 0，原始分再大也到不了 1。

阈值 0.30 压在一条缝上：应当留下的最低融合分是「下午可以住吗」0.341，应当拒绝、又不是全 0 的最高是「早到怎么办」0.274。只看向量分，这几句挤在一起（下午 0.197、时间 0.203、什么时候能入住 0.210），没有一条阈值能同时留下下午、挡住「时间」。取两路最大值，「时间」会变成 0.315，缝又没了，所以融合规定是加权，不是 max。

无关问法仍拒绝：乐队、游泳池两路都是 0，融合也是 0，不能因为多算一路就被抬过线；「可以带狗吗」最高约 0.189，第一名是取消规章（两边都有「可以」），不是宠物。小数来自当前 `hotel_faq.json` 和 `TfidfEmbedder`，要守住的是这条缝还在，不是背三位小数。

## 为什么能跑
官方练习在讲义仓根目录用已有 `.venv` 的 python 跑 `lessons/09-hybrid-retrieval/exercise.py`，走本地 `Bm25Index` / `TfidfEmbedder` / `HybridRetriever`，不联网、不读密钥。先印第 03 课三句的向量分、关键词原始分、压缩分和融合分，再说明「时间」若取最大值会过线，最后 `合计 11/11`，退出码 0。权重实验在练习副本用 `build_hybrid_retriever(vector_weight=1.0, sparse_weight=0.0)`，不改讲义仓，也不改 `hybrid_queries.json` 的期望。

## 卡过啥
- 原始 BM25 和余弦不能直接加；也不除以本问最高分。
- 不用 max：会把「时间」重新放进来。
- 混合不是突然听得懂「狗」和「宠物」；字面证据对不上就应当拒绝。
- 融合过线只决定进不进生成，还要做第 05 课的引用检查。
- 不为压住某一个字去改 `k1` / `b`；缝不对先回查询集看哪一路变了。
- 权重实验只在练习副本里做，看完讲义仓仍干净。

## 口头自查 / 练习结论
1. 「我什么时候能进房间」只对上「能进」「房间」，点积来自这两个词，长度却来自整条入住规章，余弦掉到 0.227。BM25 按对上的词往上加，文档长度只做温和归一，「能进」「房间」只出现在入住这一条，idf 高，原始分到 3.161。
2. 要留下下午（余弦 0.197），阈值就得低于 0.197，「时间」（0.203）会一起进来；要挡住「时间」，阈值就得高于 0.203，下午进不来。取最大值时，「时间」的压缩关键词分 0.315 会过 0.30。
3. 「可以带狗吗」两路都不高。把权重改到 0.9 也变不出「导盲犬」，缺的是同义词证据，要换嵌入模型，换完分数和 0.30 都要重看。

权重改成 1.0 / 0.0 后，融合分退回余弦：`paraphrase-room`（0.227）、`afternoon-checkin`（0.197）、`luggage`（0.221）过不了 0.30，这三句要靠关键词路才过线；`refuse-*` 仍通过，那些问法的余弦本来就不高。期望没改，合计变成 8/11，说明混合比单路向量稳，是因为这组问法在余弦上挨在一起，加权之后才分开。
