# 第8课：函数与学习记录统计

## 学了啥
用 `def` 定义函数：给一段工作起名字，调用时传入不同数据。`return` 交回结果；参数和函数内变量是局部的。组合列表+循环+条件：`total_minutes` / `average_minutes`（空表返回 None）/ `remaining_minutes`（达标返回 0）。练习：总页数、及格人数（含 60）、最长时长（空表 None，不用 max）。

## 为什么能跑
定义只登记菜谱，调用才跳进函数体；跑完带着 return 值跳回。每次调用局部变量重新初始化，所以两次求和不互相累加。空表先判长度再除，避免除零；`None` 表示「没有平均值」，和平均值 0 不同。

## 卡过啥
- `return` 别缩进进 for，否则只加第一条。
- 函数用 return，由调用者决定是否 print，否则外面再 print 会多一个 None。
- `>= 60` 含及格线；空列表先判再读首元素。
